# Maintainers

Mill is maintained by [Avgeek, Inc.](https://github.com/avgeek-oss). Repository ownership, releases, and security coordination belong to the Avgeek organization owners.

Use a GitHub issue for a reproducible bug, feedback or a proposal. Mill does not accept pull requests from public sources; the maintainers make the changes. For a private security report or conduct concern, use the route described in [SECURITY.md](SECURITY.md) or contact an organization owner through their GitHub profile.

Maintainers review required CI, installation evidence, schema upgrades, permission changes, and user-facing behavior before merging. Publishing a release and changing repository visibility require an organization owner's explicit approval.
