# Changelog

## 1.0.0-beta.1 (under review)

The first Mill release candidate adds a self-hosted task board with PostgreSQL persistence, team roles, account security, notifications, REST and MCP access, and Docker Compose installation. The [B1 release notes](docs/release-notes.md) describe the supported behavior. The [verification matrix](docs/b1-verification.md) records release evidence and outstanding work.

This candidate has not been declared release ready or published by this changelog.
