Keep work moving, together.

Mill is a focused task list for teams. Your team gets a clear place to plan and discuss work. Your clients get permissioned REST and MCP access. You run it on your own infrastructure.

The task list

Enough structure to find the next step.

01

Boards stay simple

Group work into boards, then search, filter and sort each list. Six fixed statuses keep the workflow easy to follow.

02

Details live with the task

Keep a stable task link, Markdown description, due date, comments and activity together. Assign a teammate or leave it unassigned.

03

People keep control

Invite teammates with Admin, Member or Viewer access. In-app notifications bring assignments and mentions back to the work.

External clients

Connect your tools with clear boundaries.

Personal API keys let REST clients act with their human owner's current permissions. MCP connections use OAuth, approved scopes and optional board limits.

Activity records the person who authorized each connection. Mill does not execute external code.

Run it yourself

Your tasks stay on your infrastructure.

Start with Docker Compose and PostgreSQL. Mill provides health checks, checksummed migrations, full database backup guidance and a documented restore path.

The current version uses private invitation links and operator-issued account recovery links. Account and task email delivery is unavailable.
