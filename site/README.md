# Product page source

The static page in this directory is superseded. Do not deploy it. The maintained homepage and documentation use the Mintlify project in `docs/mintlify`.

Edit `docs/home.mdx`, `docs/home.css`, and the guide sources, then run `pnpm docs:build`. Use `pnpm docs:dev` for the preview and `pnpm docs:screenshots` to refresh application images. Generated pages are replaced by the documentation build.

Use direct product copy, sentence case, native Mintlify navigation and document typography, and one shared header, search, and footer. Preserve technical acronyms and Mill's own artwork. Review current screenshots in both themes at desktop and phone widths. Follow [contributor guidance](../CONTRIBUTING.md#documentation) for the documentation workflow.
