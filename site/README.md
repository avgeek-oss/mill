# Historical product page draft

The static page in this directory is the superseded October 2 design draft. Do not deploy it. The maintained homepage and documentation now share the Mintlify project at `docs/mintlify`, intended for **mill.fyi**.

Edit `docs/home.mdx`, `docs/home.css` and the guide sources, then run `pnpm docs:build`. Use `pnpm docs:dev` for the unified preview and `pnpm docs:screenshots` to refresh its application images. [Documentation design review](../docs/docs-design-review.md) records the Towbar reference and the owner's typography, capitalization and copy requirements.

The old proposal for a separate static apex and docs.mill.fyi is superseded. There is no managed Mill app or hosted demo. Connecting the existing Mintlify project, publishing the reviewed content and changing DNS require their applicable authorization. No hosting switch is made by local preview work.
