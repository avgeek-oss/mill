A board keeps related work together. Use one for a product, project or team, then add the tasks you want to track.

## Create a board

Choose **Boards** under **Operate**, then **Create Board**. Enter a name, an optional description and a prefix. The prefix identifies tasks on that board: an Engineering board might use `ENG`, giving its tasks IDs such as `ENG-1`.

Prefixes must be unique across your boards. Use 2–10 letters or numbers, starting with a letter. You can change a prefix later in the board’s General settings.

## Choose a view

Boards appear alphabetically. Use the view switch beside **Create Board** to choose cards or a table.

Cards show Backlog, To Do and In Progress counts. The table adds each board’s prefix, creator and last activity. Last activity shows a relative time and the date and time of the change.

Choose a board to open its [task list](/task-lists). Members and administrators can create and update work; viewers can read it.

## Add your first task

Choose **New task** inside the board. Enter a title and, if useful, a description and acceptance criteria. Choose the task type, assignee, priority and status, then create it. Mill opens the [task page](/task-details), where each field saves independently.

## Update board settings

In the board’s secondary sidebar, choose **Settings → General**.

- **Board details** updates the board name and description.
- **Board prefix** updates its unique prefix. Existing task IDs keep their numbers and use the new prefix. Links to the tasks continue to work.

Choose the save button in the widget you changed. If someone else updates the board while you edit, Mill keeps your draft and asks you to review the current values before saving again.

## Delete a board

Administrators can choose **Danger zone → Delete board** in the board sidebar. Review the board name before confirming.

Deleting a board permanently removes its tasks, comments and attachments. There is no trash or undo; recovering that work requires a [database backup](/backup).
