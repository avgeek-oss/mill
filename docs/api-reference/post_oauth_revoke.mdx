---
title: "Revoke an OAuth token"
description: "Revokes a token for the authenticated OAuth client. A successful response has an empty body."
playground: simple
openapi: "/api-reference/openapi.json POST /oauth/revoke"
---

Authenticate the OAuth client using its registered method: none, client_secret_basic or client_secret_post. Client credentials are distinct from a user's API key.

Revokes a token for the authenticated OAuth client. A successful response has an empty body.
