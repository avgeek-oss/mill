description: "Permanently deletes the board, all its tasks and discussion. Requires write and administrator authority. Restricted grants lose the board. Confirm the exact board; there is no trash or restore endpoint."
playground: simple
openapi: "/api-reference/openapi.json DELETE /api/boards/{boardId}"
---

Administrator access with explicit administrator permission on a personal or team REST API key, or a signed-in administrator. OAuth tokens cannot call this HTTP operation.

Permanently deletes the board, all its tasks and discussion. Requires write and administrator authority. Restricted grants lose the board. Confirm the exact board; there is no trash or restore endpoint.
