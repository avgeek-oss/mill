Write access: a member/administrator with a write-enabled credential, or an authorized signed-in user.

Mark selected notifications or all notifications present at the request snapshot as read/unread. Repeated read marks preserve the first read time. Choose ids OR all:true.

Choose ids or all:true, never both. read defaults to true; false marks unread. All applies to the request snapshot, leaving later arrivals unread. Repeated read marks preserve the original receipt time. Team API keys cannot mutate personal notifications.

MCP clients can use [`mark_notifications`](/mcp-reference/mark_notifications) for this operation.
