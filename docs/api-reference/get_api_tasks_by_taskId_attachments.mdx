---

Read access: a read-enabled personal or team REST API key, or a signed-in user. OAuth clients use the corresponding MCP tool through /mcp.

List completed attachments for a task, newest first. Use `nextCursor` to continue.

Pending uploads are not listed. Metadata never contains permanent public URLs.

MCP clients can use [`list_attachments`](/mcp-reference/list_attachments) for this operation.
