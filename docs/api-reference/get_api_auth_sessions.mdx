title: "List account sessions"

playground: simple
openapi: "/api-reference/openapi.json GET /api/auth/sessions"

A signed-in human session is required. API keys and MCP bearer credentials cannot replace that session.

Lists unexpired sessions belonging to the signed-in user, including whether each session is current.
