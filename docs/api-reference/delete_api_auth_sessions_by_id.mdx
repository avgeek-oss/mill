---
title: "Revoke an account session"
description: "Revokes an owned session. Revoking the current session also clears its cookie."
playground: simple
openapi: "/api-reference/openapi.json DELETE /api/auth/sessions/{id}"
---

A signed-in human session is required. API keys and MCP bearer credentials cannot replace that session.

Revokes an owned session. Revoking the current session also clears its cookie.
