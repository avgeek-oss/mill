Edit board settings. Prefixes must be unique; changing one renames existing task identifiers while preserving task numbers and links. Send the current version to protect concurrent edits.

## Workflow

```mermaid
flowchart LR
  step0["Read current board version"] --> step1
  step1["Choose an available prefix"] --> step2
  step2["Save and refresh task identifiers"]
```

## Access and behavior

Write or Administrator OAuth consent and a member/administrator team role are required. Tools are listed and callable only when the current grant and role permit them.

A prefix change atomically renames existing task identifiers while preserving task numbers and UUID links. Existing task versions increase. Duplicate prefixes return 409 `BOARD_PREFIX_TAKEN`; stale versions conflict. Omitted fields remain unchanged.

## Arguments

| Argument         | Required | Type or meaning                                                                                            |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `boardId`        | Yes      | Board UUID, not its task prefix.                                                                           |
| `version`        | Yes      | Latest row version; stale mutations return HTTP 409.                                                       |
| `name`           | No       | string                                                                                                     |
| `description`    | No       | string                                                                                                     |
| `prefix`         | No       | string                                                                                                     |
| `idempotencyKey` | No       | One logical mutation key, reused unchanged on retries. MCP forwards it as the REST Idempotency-Key header. |

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "update_board",
    "arguments": {
      "boardId": "11111111-1111-4111-8111-111111111111",
      "version": 1,
      "prefix": "OPS",
      "idempotencyKey": "engineering-prefix-edit-001"
    }
  }
}
```

## Example result

Mill returns this object in `structuredContent` and normally a JSON text content block (large responses may shorten the text block). A tool failure sets `isError`; never treat an error as a completed mutation.
