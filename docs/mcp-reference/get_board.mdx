Read a board's settings.

## Workflow

```mermaid
flowchart LR
  step0["Choose a board UUID"] --> step1
  step1["Read current settings"] --> step2
  step2["Keep its version for edits"]
```

## Access and behavior

A Read-only, Write or Administrator OAuth grant can call this tool within the user’s current team role. Tools are listed and callable only when the current grant and role permit them.

Use the UUID in API paths. The task prefix is a human-readable identifier component, not the board ID. Creator presentation and task counts are supplied by list_boards.

## Arguments

| Argument  | Required | Type or meaning                  |
| --------- | -------- | -------------------------------- |
| `boardId` | Yes      | Board UUID, not its task prefix. |

<Accordion title="Complete input schema">

```json
{
  "type": "object",
  "properties": {
    "boardId": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    }
  },
  "required": ["boardId"],
  "additionalProperties": false
}
```

</Accordion>

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_board",
    "arguments": {
      "boardId": "11111111-1111-4111-8111-111111111111"
    }
  }
}
```
