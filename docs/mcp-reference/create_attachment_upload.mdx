Reserve an image/PDF attachment and obtain a short-lived private PUT URL. Upload file bytes directly to uploadUrl using the returned headers, then call complete_attachment. Treat URLs as temporary credentials; do not log them.

## Workflow

```mermaid
flowchart LR
  step0["Reserve upload"] --> step1
  step1["PUT exact bytes to signed URL"] --> step2
  step2["Complete attachment"]
```

## Access and behavior

Write or Administrator OAuth consent and a member/administrator team role are required. Tools are listed and callable only when the current grant and role permit them.

The signed PUT URL lasts five minutes. Upload directly using the returned headers; never forward a Mill cookie or bearer token to storage. Browsers set Content-Type and derive Content-Length from the file body.

## Arguments

| Argument         | Required | Type or meaning                                                                                            |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `taskId`         | Yes      | Task UUID, not its human identifier such as ENG-1.                                                         |
| `fileName`       | Yes      | string                                                                                                     |
| `contentType`    | Yes      | image/png, image/jpeg, image/webp, image/gif, application/pdf                                              |
| `sizeBytes`      | Yes      | integer                                                                                                    |
| `sha256`         | No       | string                                                                                                     |
| `idempotencyKey` | No       | One logical mutation key, reused unchanged on retries. MCP forwards it as the REST Idempotency-Key header. |

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "create_attachment_upload",
    "arguments": {
      "taskId": "22222222-2222-4222-8222-222222222222",
      "fileName": "restore-report.pdf",
      "contentType": "application/pdf",
      "sizeBytes": 2048,
      "idempotencyKey": "restore-report-upload-001"
    }
  }
}
```

## Example result

Mill returns this object in `structuredContent` and normally a JSON text content block (large responses may shorten the text block). A tool failure sets `isError`; never treat an error as a completed mutation.

```json
{
  "attachmentId": "44444444-4444-4444-8444-444444444444",
  "uploadUrl": "https://storage.example.test/private-upload?signature=example",
  "headers": {
    "Content-Type": "application/pdf",
    "Content-Length": "2048"
  },
  "expiresAt": "2027-01-18T09:30:00.000Z"
}
```
