Create a board. Tasks use Mill's fixed statuses.

## Workflow

```mermaid
flowchart LR
  step0["Choose a unique prefix"] --> step1
  step1["Create the board"] --> step2
  step2["Create tasks in its UUID"]
```

## Access and behavior

Write or Administrator OAuth consent and a member/administrator team role are required. Tools are listed and callable only when the current grant and role permit them.

Requires workspace-wide write access. Prefixes use 2–10 uppercase letters/digits with a leading letter; omission derives an available prefix from the name. Every board uses the same six fixed statuses.

## Arguments

| Argument         | Required | Type or meaning                                                                                            |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `name`           | Yes      | string                                                                                                     |
| `prefix`         | No       | string                                                                                                     |
| `description`    | No       | string                                                                                                     |
| `idempotencyKey` | No       | One logical mutation key, reused unchanged on retries. MCP forwards it as the REST Idempotency-Key header. |

<Accordion title="Complete input schema">

```json
{
  "type": "object",
  "properties": {
    "name": {
      "type": "string",
      "minLength": 1,
      "maxLength": 100
    },
    "prefix": {
      "type": "string",
      "pattern": "^[A-Z][A-Z0-9]{1,9}$"
    },
    "description": {
      "type": "string",
      "maxLength": 10000
    },
    "idempotencyKey": {
      "type": "string",
      "minLength": 8,
      "maxLength": 128
    }
  },
  "required": ["name"],
  "additionalProperties": false
}
```

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "create_board",
    "arguments": {
      "name": "Engineering",
      "prefix": "ENG",
      "description": "Track delivery and reliability.",
      "idempotencyKey": "engineering-board-create-001"
    }
  }
}
```
