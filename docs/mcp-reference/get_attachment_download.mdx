Obtain a short-lived private GET URL for an attachment. preview:true returns an inline image/PDF. Do not log returned URLs.

## Workflow

```mermaid
flowchart LR
  step0["Check current task access"] --> step1
  step1["Request a signed URL"] --> step2
  step2["Read before expiry"]
```

## Access and behavior

A Read-only, Write or Administrator OAuth grant can call this tool within the user’s current team role. Tools are listed and callable only when the current grant and role permit them.

URLs expire after five minutes and are private capabilities. preview:true requests inline image/PDF display; otherwise the URL downloads the attachment.

## Arguments

| Argument       | Required | Type or meaning                                    |
| -------------- | -------- | -------------------------------------------------- |
| `taskId`       | Yes      | Task UUID, not its human identifier such as ENG-1. |
| `attachmentId` | Yes      | uuid                                               |
| `preview`      | No       | boolean                                            |

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_attachment_download",
    "arguments": {
      "taskId": "22222222-2222-4222-8222-222222222222",
      "attachmentId": "44444444-4444-4444-8444-444444444444",
      "preview": true
    }
  }
}
```

## Example result

Mill returns this object in `structuredContent` and normally a JSON text content block (large responses may shorten the text block). A tool failure sets `isError`; never treat an error as a completed mutation.

```json
{
  "url": "https://storage.example.test/private-download?signature=example",
  "expiresAt": "2027-01-18T09:30:00.000Z"
}
```
