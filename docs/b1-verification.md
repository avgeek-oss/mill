# B1 verification

Mill implements the [B1 release brief](b1-release-brief.md) in one self-hosted application. The repository and PR remain private. The September 29 revision replaces archived/deleted collections with permanent deletion, shows every board in a fixed sidebar category, and moves notifications into a header popover. The September 28 results below describe the earlier candidate; they do not verify this revision.

## September 29 navigation and deletion revision

The Boards category now stays expanded, automatically loads every directory page, preserves existing rows while refreshing, and places Create Project after the final board. There is no board collection selector. Notifications use the shared header popover with bounded scrolling, All/Unread filters, read actions, and confirmed read-before-task navigation. The standalone Inbox page and sidebar item are removed.

Boards and tasks support permanent deletion only. A board deletion removes its statuses and owned tasks, while task deletion removes descendants. Comments, notifications, work activity, removed board scopes, and cached content responses are cleaned up transactionally. A minimal deletion attribution remains in audit history. Human administrators delete boards; task deletion respects Member access and current agent scopes. Both actions check the current row version and preserve a retryable deletion acknowledgment.

[Migration 005](../packages/database/migrations/005_permanent_deletion.sql) removes the old state columns. It activates archived work and permanently purges previously deleted work and descendants. [Upgrade guidance](upgrades.md) explains that behavior and the required backup before an operator upgrade. Portable exports use version 2 with preserved next task numbers; version 1 imports activate archived work and omit deleted work and descendants. No production migration or deployment is part of this revision.
