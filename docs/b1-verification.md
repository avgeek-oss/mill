# B1 verification

Mill implements the [B1 release brief](b1-release-brief.md) in one self-hosted application. The repository remains private. This matrix records implementation and observed evidence; visual acceptance has reopened and release handoff is stopped. It does not authorize publication or deployment.

## Current acceptance

The user rejected the initial interface because its sidebar, typography, buttons, inputs, empty states, and flows did not match Towbar closely enough. The private PR remains in draft; overall UI acceptance and B1 readiness remain open. The coordinating task independently accepted the bounded foundation pass: Towbar's actual application shell, public controls, typography, Widget surfaces, board/list, and representative Workspace settings route. Its [source mapping and rendered evidence](towbar-foundation-review.md) record desktop, tablet, phone, both themes, filtered-empty recovery, and client task navigation. The next authorized gates cover identity/Profile/Account Security and task/board dialogs. People, Agent access, Inbox, audit, and data-page migrations remain held. The functional/security/container results below belong to source commit `1ac35328872f1b5d1fb2a3fe1cbc795b250e2c01` and must be kept separate from acceptance and verification of a final revised candidate.

## Current verification

On 2026-09-28, `pnpm verify` passed formatting, ESLint, server/web TypeScript, documentation links, **67 real PostgreSQL API/security tests**, **5 operational tooling tests**, the production dependency audit, and the production frontend/server build. No tests were skipped. The passing suite includes maximum-length task/checklist content, long Unicode discussions, compact task relationships, and paginated REST/MCP continuations.

The production runner completed all 33 steps on the local ARM64 Docker runtime, including fresh installation, restart persistence, a reconstructed pre-004 schema upgrade, transactional full backup restore into a separate project, non-root runtime checks, and a strict Trivy HIGH/CRITICAL scan with zero findings. The initial working-tree evidence is `tmp/verification/mill-verify-1790607251474-85112541/`. A second run on clean source commit `1ac35328872f1b5d1fb2a3fe1cbc795b250e2c01` passed all 33 steps with `sourceDirty: false`; its evidence is `tmp/verification/mill-verify-1790607981871-0173d7f3/`. Each directory retains `results.json`, `evidence.json`, and individual logs. The database-outage test retained liveness 200 and returned readiness 503; restarting PostgreSQL restored both endpoints and preserved task/comment/member data. These runs verify the original implementation, not the revised UI candidate.

A separate clean checkout of commit `1ac35328872f1b5d1fb2a3fe1cbc795b250e2c01` passed `pnpm install --frozen-lockfile` and `pnpm verify` (`tmp/clean-checkout-verify.log`). Its public dependency install required no private Avgeek package or sibling checkout.

GitHub CI on the original implementation failed two test/build-environment checks while its AMD64 production job passed. The independent OAuth-audience fixture hardcoded localhost even when the configured CI origin used 127.0.0.1; the fixture now derives the canonical resource from `MILL_BASE_URL`, retaining the stale-audience and public-REST rejection assertions. The reviewer passed all 13 independent tests with each origin. The root also reran the full API suite with the CI origin and inherited production environment: **67/67 passed, zero skipped**, recorded in `tmp/root-ci-origin-api.log`. CI inherited `NODE_ENV=test` into Vite; build steps now explicitly use production mode, while isolated API/browser test servers set test mode themselves. These changes are commit `8507237edce0bb7cd9dd638c26f0dd35f1b62cb6`. Its [push run](https://github.com/avgeek-inc/mill/actions/runs/36442704568) and [PR run](https://github.com/avgeek-inc/mill/actions/runs/36442712110) both completed successfully across verify, browser, AMD64 production, and Required CI. Exact job outcomes are retained in `tmp/ci-8507237-push.json` and `tmp/ci-8507237-pr.json`. The status-field focus assertion remains strict and will be rechecked during the foundation pass. This passing source precedes the foundation changes and does not close visual acceptance.

Browser tests use an isolated random PostgreSQL schema and a running built Node server, rather than a mocked API. The default browser origin is `http://localhost:4323`, so a Chromium virtual authenticator can exercise real WebAuthn ceremonies. The developer/coordinator review surface is a separate disposable workspace at [localhost:4321](http://localhost:4321). The web owner passed all nine board journeys in 38.7 seconds; the identity reviewer passed all seven account/settings journeys in 27.9 seconds. The root combined `pnpm test:browser` run passed **16/16** in 1.1 minutes against the final stable build. Tablet filters, status focus, mobile drawer focus containment, deep links and archive/restore were verified as functional behavior. These checks do not establish visual acceptance; the user's Towbar comparison has reopened that gate.

## Reference review

Current Towbar design-system primitives, app shell, passkey/authenticator preference, OAuth/API scope, migrations, Docker, and CI were inspected read-only on 2026-09-28. Towbar's actual components and recipes are the design authority for the revised candidate. The earlier Mobbin Linear board [light](https://mobbin.com/screens/fc208a44-dbf9-4f79-b9b0-db57f9840964) and [dark](https://mobbin.com/screens/720724d3-f686-457f-8c00-fa7efa409b12) study is historical and does not establish visual acceptance. The foundation uses attributed Apache source with public HeroUI, React Aria Components, Hugeicons free icons, Inter, and Geist Mono. No paid component, private package, hosted-agent, or LLM-key requirement is introduced.
