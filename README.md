# Mill

Mill is an open-source, self-hosted task board for people and agents, created by Avgeek, Inc.

The repository is private while the first beta is built and reviewed. B1 must be a complete, usable product with a verified installation path, working features, documentation, and release artifacts. A scaffold or mock dashboard does not satisfy that goal.

The product scope and evidence required for B1 are recorded in [the release brief](docs/b1-release-brief.md).
